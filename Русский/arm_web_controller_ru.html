Своя команда

→ 90 90 90 90 90
Пример: 90 | 0 60 | 0 90 90 90 40 | s
Пределы: S0–S3 0–180°, S4 захват 0–90°, S2 инвертировано (в интерфейсе логический угол)
Прошивка принимает только цифры, пробелы, h, s; прочее отбрасывается; порт 9600 8N1

Управление серво

Главный цикл прошивки читает порт раз в 40 мс, интерполяция около 25°/с.
Страница объединяет отправку (по суставу только последнее значение) и держит интервал 45 мс, чтобы не переполнить буфер 64 байта.
После подключения раз в 1,2 с отправляется s для обновления фактических углов.
