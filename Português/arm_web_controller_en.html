Custom command

→ 90 90 90 90 90
Examples: 90 | 0 60 | 0 90 90 90 40 | s
Limits: S0–S3 0–180°, S4 gripper 0–90°, S2 is reversed inside the firmware (the UI still uses logical angles)
The firmware accepts only digits, spaces, h, s; anything else is dropped; port 9600 8N1

Servo control

The firmware main loop reads the port every 40 ms and interpolates at about 25°/s.
This page merges sends (latest value per joint only) and queues them at least 45 ms apart, so the 64-byte RX buffer never overflows.
After connecting, s is sent every 1.2 s to refresh the "actual angles".
